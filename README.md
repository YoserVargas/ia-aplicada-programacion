# IA aplicada a la programación

Curso intermedio de inteligencia artificial aplicada al desarrollo de software.

## 🎯 Objetivo

Aprender a comprender, utilizar e integrar herramientas de inteligencia artificial en el desarrollo de aplicaciones, mejorando la productividad y la resolución de problemas mediante JavaScript y otras tecnologías.
