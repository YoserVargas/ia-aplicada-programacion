# Día 05 - Limitaciones, errores y alucinaciones de la IA

## 1. Objetivo

Comprender las limitaciones de los modelos de inteligencia artificial, identificar posibles errores y aprender a verificar la información y el código generado por IA.

## 2. ¿Qué son las alucinaciones de la IA?

Una alucinación ocurre cuando un modelo genera información incorrecta, inventada o que no está respaldada por la información disponible, pero la presenta como si fuera verdadera.

Por ejemplo, una IA puede recomendar una función de JavaScript que realmente no existe.

Una respuesta bien redactada no necesariamente es una respuesta correcta.

## 3. ¿Por qué ocurren las alucinaciones?

Algunas causas son:

- Información insuficiente.
- Preguntas ambiguas.
- Limitaciones del modelo.
- Información desactualizada.
- Predicciones incorrectas.

La IA no siempre sabe cuándo está equivocada.

## 4. Errores frecuentes al programar con IA

| Error | Ejemplo |
|---|---|
| Código inexistente | Utilizar una función que JavaScript no tiene. |
| Código incorrecto | Una función que devuelve resultados equivocados. |
| Librerías inventadas | Recomendar un paquete que no existe. |
| Métodos incorrectos | Utilizar incorrectamente una función de React. |
| Seguridad deficiente | Exponer una contraseña o clave API
